# State Tax Wizard – WooCommerce Plugin

This plugin injects Minnesota and Colorado delivery fees into WooCommerce carts and syncs completed orders with the State Tax Wizard API.

## Features
- Calculates delivery fee quotes via `/api/v1/fees/quote` using HMAC signed requests.
- Adds the fee as a WooCommerce cart fee with configurable label overrides.
- Persists completed orders through `/api/v1/fees/apply` including reason codes and metadata.
- Captures integration logs (last 50 events) for troubleshooting.

## Requirements
- WordPress 6.0+
- WooCommerce 7.0+
- PHP 8.0+
- State Tax Wizard API credentials (store ID + HMAC secret)

## Setup
1. Install the ZIP generated by `package.sh` via **Plugins → Add New → Upload Plugin**.
2. Activate the plugin and open **WooCommerce → Settings → State Tax Wizard**.
3. Provide:
   - **API Base URL** (e.g. `https://api.statetaxwizard.com`)
   - **Store ID** (from the State Tax Wizard dashboard)
   - **HMAC Secret** (rotate from the Settings UI after installation)
   - Enable MN/CO jurisdictions as needed
4. Save the settings. The plugin immediately begins requesting cart quotes and syncing orders.

## Testing
```bash
composer install
./vendor/bin/phpunit tests/test-fee-calculator.php
```

## Packaging
```bash
./package.sh
```

The script emits `dist/state-tax-wizard-woocommerce-0.1.0.zip` ready for upload or CI distribution.

## Environment Variables (optional)
- `STW_API_BASE_URL`: Overrides the configured base URL during development.
- `STW_DEBUG`: When set, logs verbose context to `wp-content/uploads/state-tax-wizard.log`.

## Troubleshooting
- Ensure WordPress has write access to `wp-content/uploads` for log storage.
- Verify the system clock and PHP `date.timezone` configuration; skew beyond ±5 minutes causes HMAC failures.
- Check `/api/v1/integrations/status` for the store to confirm the WooCommerce provider is enabled.
