# Evidence Directory

This directory contains validation evidence for milestones 4 and 5.

## Contents

### M4 Security Evidence

- `security_smoke_output.txt` - Output from `make security-smoke`
- `metrics_dump.txt` - `/metrics` endpoint output showing security counters
- `screens/` - Screenshots of UI demonstrating security features
- `headers_scan.txt` - Generated via `make evidence-scan`; captures references to
  the custom headers (`X-RDF-*`) across code, docs, and tooling.
- `hmac_secret_scan.txt` - Also generated by `make evidence-scan`; lists where
  HMAC secrets are documented or referenced for quick review.

### M5 Billing Evidence

- `billing_smoke_output.txt` - Output from `make billing-smoke` (if Stripe configured)
- `entitlements_test.json` - Sample entitlements API response
- `usage_test.json` - Sample usage API response
- `screens/` - Screenshots of billing UI

### Screens Directory Structure

```
screens/
├── dashboard.png          # Dashboard with analytics
├── settings_hmac.png      # Settings showing HMAC rotation
├── billing_plans.png      # Billing page with plan selection
├── billing_usage.png      # Usage meter and limits
├── logs.png               # Audit logs view
└── reports.png            # Reports export history
```
