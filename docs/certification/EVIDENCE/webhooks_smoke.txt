# Smoke Webhooks – execução automatizada via GitHub Actions (`Backend CI / smoke-newman`)
# Comando executado na pipeline:
#   SMOKE_API_BASE_URL=http://127.0.0.1:8000/api \
#   SMOKE_METRICS_URL=http://127.0.0.1:8000/metrics \
#   python backend/smoke_test.py --webhooks-only
# A saída completa da execução (sucesso/erro) é anexada ao artifact `smoke-webhooks.txt` em cada run da branch principal.

# Execução manual fora da pipeline:
# 1. Inicie Postgres/Redis (`docker compose -f docker-compose.yml up -d db redis`).
# 2. Exporte `DATABASE_URL=postgresql+psycopg://user:pass@localhost:5432/rdf`.
# 3. Rode `alembic upgrade head` e inicie o backend (`uvicorn app.main:app --host 0.0.0.0 --port 8000`).
# 4. Execute `python backend/smoke_test.py --webhooks-only`.
# 5. Salve a saída neste arquivo e no artifact da certificação.

# Em ambientes sem Docker (como esta sandbox), siga a alternativa documentada:
#   python backend/smoke_test.py --webhooks-only --capture-server http://127.0.0.1:8082
# garantindo que um servidor HTTP (ex.: `python -m http.server 8082`) esteja ativo para receber o POST de webhook.
