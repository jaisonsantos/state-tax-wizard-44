# Panorama das integrações

Esta seção reúne os guias necessários para conectar plataformas externas ao State Tax Wizard. Cada documento descreve requisitos, passos de instalação e dicas de suporte específicas para o provedor correspondente.

## Guias disponíveis

- [Shopify](shopify.md): instruções para configurar a integração com lojas Shopify, incluindo autenticação, webhooks e sincronização de pedidos.
- [WooCommerce](woocommerce.md): passo a passo para ativar a integração no WordPress, com detalhes sobre plugins, credenciais e validação de pedidos.
- [Suporte e operações](support.md): referências para diagnosticar problemas, revisar logs e colaborar com o time de suporte.
- [Onboarding de plataformas](platform-onboarding.md): checklist para novos parceiros e ambientes de testes.
- [Testes e QA](testing.md): orientações sobre cenários de testes automatizados e manuais.
- [Exemplos de cliente HMAC](hmac-client-examples.md): exemplos de código para assinar requisições usando o padrão HMAC.

Para integrações adicionais ou dúvidas sobre fluxos específicos, consulte também os materiais em `docs/webhooks` e `docs/api`, ou entre em contato com o time de suporte interno.
